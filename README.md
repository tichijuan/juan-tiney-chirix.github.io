# Juan Tiney Chirix, Ph.D. — Academic Portfolio

A responsive academic portfolio built with semantic HTML, CSS, and vanilla JavaScript. The visual and information architecture are organized around Juan Tiney Chirix's concept of the **Methodological Shoreline**: a space of encounter among water, territory, body, memory, community, and knowledge.

## Files

- `index.html` — complete single-page academic portfolio
- `styles.css` — visual system, responsive layout, typography, animation
- `script.js` — mobile navigation, scroll reveals, active navigation, interactive Methodological Shoreline nodes
- `assets/Juan_Tiney_Chirix_CV.pdf` — replace with the final CV PDF

## Deploy

This is a static site and can be hosted on GitHub Pages, Netlify, Vercel, or any standard web host. No build step is required.

## Design principle

The shoreline is not treated as decoration. It is the site's organizing metaphor: navigation, research structure, method visualization, typography, and visual rhythm all evoke movement between disciplines, places, forms of knowledge, and communities.
